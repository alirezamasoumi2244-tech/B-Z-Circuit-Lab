# Roadmap

A screen is not proof an engine is complete. Each milestone requires tests, documented limits and a successful Windows build.

1. Foundation — in progress: desktop shell, bilingual UI, CI and shared circuit schema.
2. Domain core — planned: pins, nets, connections, validation, persistence, undo/redo, migrations.
3. Catalog — planned: licensed data pipeline, SQLite, indexed search and verified 1M+ records.
4. Schematic — planned: symbols, wiring, net highlighting and electrical rule checks.
5. Breadboard — planned: hole-level connectivity synchronized with schematic.
6. Simulation — planned: ngspice, digital engine, virtual instruments and model-based power analysis.
7. Arduino — planned: compilation, supported AVR execution, serial monitor and pin states.
8. 3D Interactive Lab — planned: Three.js assets linked to actual circuit and simulation state; orbit, zoom and interactive controls.
9. AI image import — planned: perspective correction, recognition, confidence and user confirmation.
10. PCB — planned: layout, footprints, checks and KiCad-compatible export.
11. Release — planned: automated tests and reproducible Windows installer.
